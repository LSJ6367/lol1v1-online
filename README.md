# 1v1 온라인 (테스트 버전)

## 실행 (Node 18 이상, 설치할 패키지 없음)
```
node server/server.js
```
- 켜지면 주소가 출력됩니다. 예: `http://localhost:8080`, `http://192.168.0.12:8080`
- **같은 와이파이의 폰/다른 PC**에서는 `192.168...` 주소로 접속하면 바로 대전할 수 있어요.
  (윈도우 방화벽이 묻는다면 "허용")
- 포트 변경: `PORT=3000 node server/server.js`
- 클라이언트 코드를 고친 뒤에는 서버를 다시 켜면 `public/index.html`이 자동으로 다시 만들어져요.
  (수동: `node tools/build.js`)

## 플레이
1. 한 명이 **방 만들기** → 4자리 코드가 뜸
2. 다른 한 명이 코드를 넣고 **코드로 참가**
3. 챔피언 고르고 둘 다 **준비** → 3초 후 시작
4. 승리: 상대 처치 1회 또는 상대 포탑 파괴 (`shared/protocol.js`의 `WIN`에서 변경)
- **테스트 방 만들기**: 허수아비 + 테스트 도구, 혼자서도 시작 가능, 혼자일 때는 승패 없음
- **혼자 연습(오프라인)**: 서버 없이 브라우저 안에서 실행

## 인터넷으로 친구와 하려면
이 폴더를 Node를 돌릴 수 있는 호스팅(Render, Railway, Fly.io 등)에 올리고 시작 명령을 `node server/server.js`로 지정하면 됩니다. 호스팅이 주는 `PORT` 환경변수를 자동으로 씁니다. https 주소에서는 자동으로 `wss://`로 연결됩니다.

## 구조
- `shared/core.js` 게임 규칙 (서버가 정답으로 실행, 클라이언트는 예측에 사용)
- `shared/protocol.js` 통신 약속 (메시지, 입력 프레임, 승리 조건)
- `server/` WebSocket·방·게임 루프 / `client/` 화면·입력·로비 / `tools/build.js` 한 파일로 묶기
- 자세한 설계: `DESIGN.md`
