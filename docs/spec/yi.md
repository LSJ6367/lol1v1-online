마스터이 패시브 - 2연속 공격-

설명 : 매 4번째 기본 공격마다 마스터 이가 2번 연속 공격합니다. 연속 공격의 두 번째 공격은 (0.5 *공격력)의 물리 피해를 입힙니다.

연속공격의 두번째 공격도 기본 공격으로 판정해. 그래서 패시브를 적용시켜서 평타를 보면 평 - 평 - 평 - 평평 - 평 -평 - 평평.. 이 되는 거임. 

-마스터이 액티브 스킬-

스킬 1 : 일격필살

사용 시 : 마스터 이가  맵에서 사라지고 공격대상으로 지정할 수 없는 상태로 대상에게 순간이동한 후 대상 주변 적들을 순식간에 4회 공격함(노란색 베기 모션).

아직은 미니언이 없기 때문에 같은 적을 4번 연속 빠르게 공격하면 됨. 자세한 메커니즘은 미니언 나오면 다시 설명함. 사거리는 600이고, 대상 지정이기 때문에 스킬을 사용하면 600 범위 내의 상대 챔피언을 그냥 자동으로 공격하게 해줘. 시전시간은 없고 즉발인데 마스터이가 맵에서 사라진 후 0.2초 후부터 대상을 공격함. 사라져서 한 대상을 4회 타격하는데 걸리는 시간은 1초보다 살짝 짧아. 그리고 사라진 후 나타날 때는 대상의 주변에서 나타나. 기본공격 1회 적중마다 남은 쿨타임이 1초씩 감소되는 스킬임.

대미지를 알려줄게.
35 / 70 / 105 / 140 / 175 (+1.225 총 공격력) 스킬 레벨이 올라가도 공격력 배수는 1.225로 같아.

마나 소모량을 알려줄게.
50/ 55 / 60 / 65 / 70

쿨타임을 알려줄게
20 / 19.5 / 19 / 18.5 / 18


스킬 2 : 명상

사용 시 : 마스터 이가 정신을 집중해 최대 4초 동안 체력을 회복함. 회복량은 마스터 이가 잃은 체력에 비례해 최대 100%까지 증가함. 

이 스킬은 중간에 조이스틱을 움직여서 끊을 수 있고, 일반적으로 상대의 공격으로는 끊기지 않지만 군중제어기( 공중에 뜸 등)을 맞으면 끊겨. 시전시간은 0초이고, 발동되면 밑에 바 형태로 4초 타이머가 시작됨(자신한테만 보임. 명상할 떄 주변에 초록 아우라 이펙트 생기게 해줘. 그리고 명상 중에 1초 마다 기본 공격 스택이 쌓여서 스택 0이어도 명상 4초동안 하면 끝나고 바로  다음 공격에 패시브 2연속 공격 발동되게 할 수 있음. 이 스킬의 쿨타임은 명상 사용중에도 돌아감. 그리고 명상 발동 직후 0.5 초에는 받는 피해 70% 감소를 얻고 명상 중과 명상 끝난 후 0.5초 동안은 레벨에 따라 ( 45% / 47.5% / 50% / 52.5% / 55%/) 받는 피해 감소를 얻음. 이 피해 감소 효과는 포탑을 상대로는 절반으로 감소함.

일단 스킬의 1초당 체력 회복량은 다음과 같아 (이것도 1레벨회복량/2레벨…/5레벨 회복량+ (계수)으로 서술함)
: 30 / 50 / 70 / 90 / 100 + (주문력 * 0.25)
그리고 잃은 체력 1%당 스킬의 전체 체력 회복량이 1% 증가해. 참고로 주문력은 나중에 아이템 추가될 떄 같이 추가될거임.


마나 소모량을 알려줄게
레벨에 상관 없이 (40 + 초당 최대마나 6%) 소모함

쿨타임은 10초임.


스킬 3 : 우주류 검술

사용 시 : 마스터 이의 기본 공격이 지속 시간 5초 동안 고정 피해를 추가로 입힘.

일격필살 써서 마스터이 가 사라진 동안과 명상 중에는 우주류 검술의 지속시간이 줄어들지 않아. 시전시간은 0초임.

추가 고정피해를 알려줄게
20 / 25 /30 /35 /40 ( + 0.35 *공격력)

마나 사용량은 없어.

쿨타임은 14초야.



궁극기 : 최후의 전사

기본 지속 효과 : 챔피언 처치 관여 시 마스터 이의 기본 스킬의 남은 재사용 대기시간이 70% 감소합니다(1ㄷ1이라 지금 구현할 필요는 없음)

사용 시: 마스터 이가 무아지경에 빠져 7초 동안 이동 속도, 공격 속도를 얻고 둔화 효과에 면역됨.

추가 이동속도는 40 %를 얻고
추가 공격속도는 25%를 얻음.

마나 사용량은 100이야.

쿨타임은 85초야.
