# 1대1 대전 · 구글 스크립트 설정 (iPad)

이 설정은 **처음 한 번만** 하면 됩니다. 마지막에 나오는 **웹 앱 URL**을 친구에게 보내면 함께 할 수 있어요.

준비물: 구글 계정, Safari 브라우저

---

## 1. 새 프로젝트 만들기
1. Safari에서 `script.google.com`에 들어가 구글 계정으로 로그인합니다.
2. **새 프로젝트**를 누릅니다.

## 2. 코드 붙여넣기
1. 새 탭을 열고 아래 주소로 들어갑니다. 글자만 보이는 화면이 나와요.
   `https://raw.githubusercontent.com/LSJ6367/lol1v1-online/main/gas/Code.gs`
2. 글자를 길게 눌러 **전체 선택 → 복사**합니다.
3. 스크립트 편집기로 돌아와 기존 코드(`function myFunction() {}`)를 **전부 지우고** 붙여넣습니다.
4. 상단의 **저장** 아이콘(디스크 모양)을 누릅니다.

> 편집 화면이 너무 작거나 메뉴가 안 보이면 주소창 왼쪽의 **aA**를 눌러 **데스크톱 웹사이트 보기**를 켜세요.

## 3. 웹 앱으로 배포하기
1. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. 왼쪽 위 톱니바퀴(유형 선택)에서 **웹 앱**을 고릅니다.
3. **다음 사용자로 실행**: **나**를 고릅니다.
   게임 페이지가 내 계정으로 돌아갑니다. 친구는 권한을 줄 필요가 없어요.
4. **액세스 권한이 있는 사용자**를 고릅니다.
   - **모든 사용자**: 링크만 있으면 누구나 들어올 수 있습니다. 친구가 구글 계정이 없어도 돼서 가장 간단합니다.
   - **Google 계정이 있는 모든 사용자**: 학교 계정으로 만들었을 때 '모든 사용자'가 안 보이거나 막혀 있으면 이걸 고르세요. 이 경우 친구도 구글 계정으로 로그인해야 합니다.
5. **배포**를 누릅니다.

## 4. 권한 승인 (처음 한 번)
1. **권한 승인** 창이 뜨면 내 계정을 고릅니다.
2. "Google에서 확인하지 않은 앱"이라는 경고가 뜹니다. 내가 직접 만든 스크립트라서 나오는 정상적인 경고예요.
   **고급 → (프로젝트 이름)(안전하지 않음)으로 이동 → 허용**을 누릅니다.
   이 스크립트는 게임 파일을 GitHub에서 받아오고, 방 연결 정보를 잠시 저장하는 일만 합니다.

## 5. 링크 공유하기
1. 배포가 끝나면 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)이 나옵니다. **복사**를 눌러 친구에게 보내세요.
2. 내 iPad에서도 그 링크를 열어 게임 화면이 나오는지 확인합니다.

---

## 업데이트하는 법
- **게임 화면이나 기능을 고쳐서 GitHub에 올렸을 때**: 자동으로 반영됩니다. 최대 5분쯤 걸릴 수 있어요. 바로 보고 싶으면 링크 끝에 `?nocache=1`을 붙여 여세요.
- **Code.gs를 고쳤을 때만**: 2번(코드 붙여넣기)부터 다시 하고 저장한 뒤, **배포 → 배포 관리 → 연필(수정) 아이콘 → 버전: 새 버전 → 배포**를 누릅니다.
  주의: **새 배포**를 하면 링크가 바뀝니다. 새 배포는 처음 한 번만 하세요.

## 문제 해결
- **"게임 페이지를 불러오지 못했어요"가 나와요**: 잠시 뒤 새로고침하세요. 계속 같으면 인터넷 연결을 확인하고, 그래도 안 되면 방장에게 알려 주세요.
- **권한 오류가 나와요**: **배포 → 배포 관리**에서 '다음 사용자로 실행: 나'와 액세스 권한을 확인한 뒤, 다시 권한 승인을 하세요.
- **방은 만들었는데 친구가 들어오지 못해요 (연결 실패)**:
  - 두 기기를 **같은 와이파이**에 연결하세요.
  - **학교 와이파이나 공공 와이파이**는 기기끼리의 연결을 막는 경우가 많아요. 이때는 한 사람의 휴대폰 **개인 핫스팟**에 두 기기를 연결하면 대부분 됩니다.
  - 모바일 데이터(LTE/5G)끼리는 직접 연결이 안 될 수 있어요.
- **게임 도중에 멈춰요**: 방을 만든 사람(방장)의 화면이 꺼지거나 다른 앱·탭으로 나가면 게임이 멈춥니다. 방장은 화면을 켜 둬 주세요.
  자동 잠금 끄기: **설정 → 디스플레이 및 밝기 → 자동 잠금 → 안 함**
- 방 코드는 4글자이며 **0, 1, I, O는 쓰지 않아요**. 헷갈리면 다시 확인하세요.
